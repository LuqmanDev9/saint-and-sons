# Saint & Sons — Premium Barbershop

A luxury barbershop website combining modern design, premium grooming services and an interactive appointment booking system.

## Features

- Responsive black-and-gold luxury design
- Individual service pages
- Bento Grid gallery
- Smooth scroll animations
- Five-step appointment booking system
- REST API integration
- SEO metadata, sitemap and robots.txt

## Tech Stack

**Frontend**
- Next.js
- React
- Tailwind CSS
- Motion
- Lucide React

**Backend**
- Node.js
- Express.js
- REST API

## Getting Started

Install dependencies:

`npm install`

Start the frontend:

`npm run dev`

Start the backend in a separate terminal:

`node server.js`

Frontend: http://localhost:3000

Backend: http://localhost:5000

## API Endpoints

| Method | Endpoint |
|---|---|
| GET | /api/services |
| GET | /api/barbers |
| POST | /api/bookings |
| GET | /api/bookings |

## Project Status

Built as a full-stack portfolio project. Bookings are stored temporarily in memory without a database. The booking system is intended for demonstration purposes.
